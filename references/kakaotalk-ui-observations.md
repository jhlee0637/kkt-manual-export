# 창 구조
- 채팅창: 클래스 `EVA_Window_Dblclk`, 제목은 방 이름. 입력창 `RICHEDIT50W`, 메시지 목록 `EVA_VH_ListControl_Dblclk`, 스크롤 `_EVA_CustomScrollCtrl`로 구성된다.
- 메시지 항목은 UI Automation에 노출되지 않는다. 읽히는 것은 목록·입력창·검색창의 사각형뿐이다.
- 메인 창 제목은 `카카오톡`. 서랍(`채팅방 서랍`)과 완료 팝업(제목 없음)도 같은 클래스의 별도 최상위 창이다.
- 창 핸들은 창이 다시 만들어지면 바뀐다(시험 중 한 번 바뀜). 핸들을 저장하지 말고 매번 제목으로 찾는다.
- 창 크기: 높이가 작으면(450) 메시지 목록이 약 194px, 800이면 약 544px. 수집은 380×800으로 맞추고 끝나면 원래 크기로 복원한다.
# 입력과 캡처

| 방법 | 결과 |
|---|---|
| `SendInput`(키, 마우스) | 동작. 대상 창이 포그라운드여야 한다 |
| `PostMessage`로 키·클릭 전달 | 동작하지 않음 |
| `PrintWindow`(플래그 2) 캡처 | 가려진 창도 캡처됨. 포커스를 가져가지 않음 |
| `Ctrl+A`, `Ctrl+C` | 텍스트가 복사되지 않음. 사진은 이미지 형식으로만 복사됨 |
| 마우스 휠 | 메시지 목록 스크롤 동작 |
# 메뉴
- `더보기(≡)`: 창 폭 −22, 위에서 57px. 380×640과 1085×450에서 확인했다. 380×800은 눌러 보지 않았다.
- 메뉴 항목 위치는 창이 아니라 `≡` 기준으로 일정하다. `채팅방 서랍`은 `≡`에서 아래 93px, 왼쪽 약 42px.
- 하위 메뉴(`채팅방 서랍`, `대화 내용`)는 클릭으로 열리지 않는다. 항목 위에서 마우스를 움직인 뒤 오른쪽 방향키로 연다. 항목 선택은 아래 방향키 후 `Enter`.
- `대화 내용` 하위: `대화 내보내기 (Ctrl+S)`, `채팅방 저장소에 저장`(유료 톡클라우드 안내, 사용하지 않음), `대화 내용 모두 삭제`(파괴적, 바로 인접).
- 안전: 방향키로 `대화 내용` 하위 항목을 고르지 말고 `Ctrl+S` 단축키만 쓴다.
# 내보내기와 저장 대화상자
- 채팅창에서 `Ctrl+S` → 표준 저장 대화상자. 기본 파일명 `KakaoTalk_YYYYMMDD_HHMM_SS_mmm_group.txt`(누른 시각). 1:1 방의 접미사는 미관측이다.
- 파일 안의 `저장한 날짜`는 파일명 시각보다 몇 초 늦다(실제 저장 시각).
- 대화상자는 마지막 폴더를 기억한다. 파일명 칸과 저장 버튼은 win32 메시지(`WM_SETTEXT`, `BM_CLICK`)로 포커스 없이 다룰 수 있다.
- 완료 팝업(`대화 내보내기 … 완료`)은 별도 창이다. `Enter`로 닫히지만 입력창이 포커스일 때 `Enter`를 보내면 작성 중인 글이 전송될 수 있다. 포커스가 팝업일 때만 보낸다.
# 서랍과 사진
- 서랍은 별도 창이다. 왼쪽에 이 계정의 모든 방 목록이 보이므로 시험 방 외에는 건드리지 않는다.
- 오른쪽은 `사진/동영상`·`파일`·`링크` 탭, 최신순, 가로 3개 격자(간격 132px), 위에 전체 개수가 표시된다.
- 썸네일을 누르면 뷰어가 아니라 선택 모드가 된다. 선택 원은 썸네일 중심에서 대략 (−47, −45). `Ctrl+A` 전체 선택은 안 된다. 아래 `N개 선택`의 다운로드 아이콘으로 저장한다.
- 저장된 사진 파일명은 `KakaoTalk_YYYYMMDD_HHMMSSmmm.ext`이고 시각이 메시지와 분 단위로 일치한다. 같은 사진을 다시 저장하면 이름 뒤에 ` (1)`이 붙는다.
- 기본 저장 폴더(`문서\카카오톡 받은 파일`)에는 사용자의 다른 파일이 섞여 있다. 위 파일명 패턴만 읽는다.
- 원본 JPEG에는 촬영 기기와 시각 같은 EXIF가 들어 있다. 공유할 때는 제거 정책이 필요하다.
## 서랍 열기와 저장 (Windows, 2026-10 실측: 380x800 창에서 자동화 성공)
- `≡` → `채팅방 서랍`(≡ 에서 아래 93px, 왼쪽 42px)에 마우스를 올리고 `오른쪽 방향키` → 하위 메뉴는 `사진/동영상`, `파일`(Ctrl+J), `링크`. `아래 방향키` → `Enter` 로 `사진/동영상`을 연다. 모두 읽기 항목이다.
- 서랍 창 제목은 `채팅방 서랍`(별도 최상위 창, 시험 시 840x600). 머리에 방 이름과 탭, 오른쪽 위에 전체 개수(`2개`)가 있다. 글자는 직접 그려서 읽을 수 없다.
- 격자: 왼쪽 끝 284px, 칸 124px, 간격 132px, 가로 3개. 월 머리글(`2026-10`) 아래에서 시작한다. 월 머리글에는 전체 선택 동작이 없다.
- 선택 원은 마우스를 올려야 생기고(칸 왼쪽 위 (15,16)), 선택하면 노란 체크가 된다. 선택은 화면에 유지된다.
- 선택하면 아래에 `N 개 선택` 바가 생긴다. 오른쪽 아이콘 둘: **왼쪽(너비−80)은 전달(공유), 오른쪽(너비−40, 높이−30)이 다운로드**다. 전달을 누르면 안 된다.
- 다운로드는 저장 대화상자 없이 기본 폴더(`문서\카카오톡 받은 파일`)에 바로 저장한다. 같은 이름이 있으면 ` (1)`, ` (2)` 가 붙는다 (같은 사진을 다시 받으면 쌓인다).
- 저장 후 `저장 결과` 팝업(별도 창, 제목 없음, 300x200: `저장 완료 : N개 / 실패 : M개`, `폴더 열기`)이 뜬다. **`Esc` 로 닫는다.** `Enter` 는 `폴더 열기` 를 누를 수 있어 쓰지 않는다.
- 미확인: 사진이 많아 스크롤해야 할 때의 동작, 동영상(사진/동영상 탭에 섞임) 저장, 한 번에 선택할 수 있는 최대 개수, 월이 여러 개일 때.

# 말풍선
- 삭제된 메시지는 가운데 정렬된 `메시지가 삭제되었습니다.` 말풍선이고 시각 표시가 없다.
- 수정된 메시지에는 화면에서 `수정됨` 표시가 보이지만 TXT에는 없다.
- 답장 말풍선의 인용 영역을 누르면 원본 메시지로 스크롤된다. 원본은 목록 중앙 부근에 놓인다(2회 관측). 삭제된 원본이나 아주 오래된 원본의 동작은 미확인이다.
